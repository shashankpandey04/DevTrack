# DevTrack — Task Management REST API

DevTrack is a RESTful task management API built with Java and Spring Boot. It provides endpoints to create, retrieve, update, partially update, and delete tasks, with support for task priorities, statuses, descriptions, and due dates.

The project focuses on building a maintainable backend using REST principles and Spring Boot best practices, with plans to integrate PostgreSQL for persistent storage and Spring Security for authentication and authorization.

### Tech Stack
- **Language:** Java 21
- **Framework:** Spring Boot
- **Build Tool:** Maven
- **Database:** PostgreSQL
- **API Style:** REST

### Features
- Create and retrieve tasks
- Retrieve individual tasks by ID
- Update tasks partially using PATCH
- Delete tasks by ID
- Task status and priority management
- Due date and description support
- Appropriate HTTP status codes for API responses

### Project Goals
- Learn Spring Boot through hands-on development
- Apply REST API design principles
- Implement a layered architecture with controllers and services
- Integrate database persistence and authentication
- Build a foundation for a production-ready backend application
